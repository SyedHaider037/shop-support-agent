What do these mean?
Summary
Latency is the whole request. Tokens are what the model read and wrote. Cost is an estimate from list prices.
Steps
Each step is one model call; its latency includes any retries. Risk: low reads data, medium saves contact details, high asks for a refund.
Guardrails
Input checks run before the model; output checks run on the final reply.
Retries and waits
Calls repeated after a rate limit, a server error or a malformed tool call.
Error code
Set when the agent stopped early, for example at a step limit or after a refused input.
